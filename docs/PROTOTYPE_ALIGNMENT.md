# 原型对齐清单（2026-09-16）

基准：《产品原型图》（10 页视觉稿）。
实现层：新增 `prototype.css`，在 `life.css`、`experience.css` 之后加载，只覆盖视觉与排版。
数据模型、存储键（`life-plus-one-review-experience-v1`）、`data-*` 交互钩子均未改动。

## 保留的既有能力（原型未体现）

- 人生清单卡片的编辑 / 删除 / 完成并记录按钮：为满足触控与验收可点，保留为卡片下方工具行。
- 时间轴与搜索页的年份筛选、排序、城市筛选。
- 记录详情页的照片预览、编辑、收藏、删除。
- 心愿与记录的关联关系（完成后心愿置为已完成，删除记录后恢复）。

## 已知差异

- 心情使用 emoji 圆形按钮，原型为绘制图标。
- 照片素材沿用 codex 版本，未按原型替换。
- 地图为足迹示意区，未接入真实地图 SDK。

面向"更像手机、更少遮挡"的桌面预览体验，`prototype.css` 追加以下覆盖：

| 项 | 修订前 | 修订后 |
