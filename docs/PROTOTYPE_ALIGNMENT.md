# 原型对齐清单（2026-09-16）

基准：《产品原型图》（10 页视觉稿）。
实现层：新增 `prototype.css`，在 `life.css`、`experience.css` 之后加载，只覆盖视觉与排版。
数据模型、存储键（`life-plus-one-review-experience-v1`）、`data-*` 交互钩子均未改动。

## 保留的既有能力（原型未体现）

- 人生清单卡片的编辑 / 删除 / 完成并记录按钮：为满足触控与验收可点，保留为卡片下方工具行。
- 时间轴与搜索页的年份筛选、排序、城市筛选。
- 记录详情页的照片预览、编辑、收藏、删除。
- 心愿与记录的关联关系（完成后心愿置为已完成，删除记录后恢复）。

## 已知差异

- 心情使用 emoji 圆形按钮，原型为绘制图标。
- 照片素材沿用 codex 版本，未按原型替换。
- 地图为足迹示意区，未接入真实地图 SDK。

## 第二轮修订（桌面壳体）

面向"更像手机、更少遮挡"的桌面预览体验，`prototype.css` 追加以下覆盖：

| 项 | 修订前 | 修订后 |
| --- | --- | --- |
| 品牌 logo | 上一轮把「+1」压到 34px、名称字重提到 700 | 全部还原为 codex 原值（侧栏 49px / 页眉 44px，名称 550–600 字重），不再覆盖 |
| 桌面页面背景 | 被 `.app-backdrop` 覆盖成纯色 | 还原 codex 的湖景渐变 + `cover-landscape.png` |
| 面板比例 | 460×591（≈0.78，近方形） | 420×629（≈0.67），上下留白 24/18 |
| 页眉底色 | `rgba(252,253,255,.96)` 半透明，滚动时下方内容透出 | 纯白不透明 |
| 滚动后页眉 | 81px 高，`+1` 44→32px | 51px 高，`+1` 24px、名称 11px、图标按钮 32px（需同时覆盖 `min-height:44px`） |

自查脚本：`verify-desktop-shell.cjs`（1536×703 渲染、滚动前后各截图一次并输出关键尺寸）。

## 第三轮修订（品牌与首页卡片）

| 项 | 修订前 | 修订后 |
| --- | --- | --- |
| 首页品牌 | codex 原值：`+1` 44px、距面板左 20px、上 39px | `+1` 34px、距面板左 10px、上 22px；名称 12px、副标 8.5px（字形与字重仍沿用 codex） |
| 首页卡片格式 | 仅原型照片版 | 新增 codex 简洁版，用户可在页面上切换；选择写入 `life-plus-one-review-home-style`，刷新后保持 |
| 简洁版卡片 | — | 浅色渐变 + 右侧露出湖景照 + 深蓝数字 + `+1` 徽标 + 手写体落款；页面上方恢复「嗨，今天也很高兴见到你」问候行 |
| 六宫格文案 | 纯数字统计（如 `0/3`、`3`、`2`） | 采用 codex 说明文案：`3 件小小心愿` / `3 座城市的故事` / `2 次勇敢尝试` / `1 份味觉记忆` / `0 场光影之旅` / `关于我的小小宇宙`，数字用各宫格强调色 |
| 六宫格标题 | 1000个第一次 / 美食记录 / 电影记录 | 第一次 / 美食 / 电影（与 codex 一致） |

实现要点：

- 切换控件为小胶囊（视觉 28px），按钮盒仍保留 44px 触控区——`verify-experience.cjs` 会检查所有 button 的点击面积。
- 桌面面板内首个子元素的负 `margin-top` 会被滚动容器夹住，因此品牌上移改为调整 `.page-content.page-home` 的顶部留白（16px）。
- 两种格式互不影响数据层：照片版沿用原型文案，简洁版沿用 codex 文案。

自查脚本：`verify-home-cards.cjs`（品牌几何 + 两种卡片 + 切换持久化 + 六宫格文案，并输出 `verification/home-photo.png`、`home-classic.png`、`home-375-*.png`）。
