## 保留的既有能力（原型未体现）

- 人生清单卡片的编辑 / 删除 / 完成并记录按钮：为满足触控与验收可点，保留为卡片下方工具行。
- 时间轴与搜索页的年份筛选、排序、城市筛选。
- 记录详情页的照片预览、编辑、收藏、删除。
- 心愿与记录的关联关系（完成后心愿置为已完成，删除记录后恢复）。

## 已知差异

- 心情使用 emoji 圆形按钮，原型为绘制图标。
- 照片素材沿用 codex 版本，未按原型替换。
- 地图为足迹示意区，未接入真实地图 SDK。

## 第四轮修订（页眉：两个圆角浮块）

把页眉从「一条通栏的白色矩形」改成「左右两个与底色同色的圆角浮块」，滚动时两块钱
向左、右两个角落缩小滑动。

| 项 | 修订前 | 修订后 |
| --- | --- | --- |
| 页眉容器 | 通栏、`background:#fff`、直角 | 透明、不画底色；左右外边距 −20px 让同色遮罩铺满面板 |
| 两块本体 | 品牌块 + 图标块，无背景 | 各自是一个圆角胶囊（`border-radius:23px`、`background:var(--pro-canvas)`、轻投影） |
| 品牌 | `+1` 34px，块 158×47 | `+1` 28px、名称 11px、副标 8px，胶囊 168×46，文字距胶囊左 10px、上 9px |
| 图标 | 22px 图标 / 44px 按钮 | 19px 图标，按钮仍 44px（触控区不变） |
| 页眉总高 | 78px（移动端）/ 72px（桌面） | 62px（两端一致） |
| 滚动后 | 仅字号略缩，容器不变 | 两块 `scale(.8)` + 向左右各平移 6px、向上 2px；`transform-origin` 取外侧上角，视觉上朝角收进去 |
| 内容透出 | 底色 96% 半透明，滚动时内容透出 | 页眉 `::before` 一层同色柔化遮罩（不透明到 76%，再渐隐到 16px 外） |
| 内容穿顶 | 移动端 `top:32px`，滚动时内容从页眉上方穿过 | `top` 由 JS 写入：窗口滚动时避开顶部固定横幅、面板内滚动时为 0 |

实现要点（都是踩过的坑）：

- **sticky 元素越不过父级内容盒上边。** 顶部留白原本挂在 `.page-content.page-home` 的
  `padding-top` 上，页眉贴顶后只能停在内容盒上边，留下一条 10px 的缝让内容露出。
  改成把留白放进页眉自己的 `padding-top`。
- **顶部有一条 `position:fixed` 的验收横幅**（`.review-banner`，z-index 60），页眉贴顶
  会被它压住。`life.js` 把横幅实际高度写进 `--header-sticky-top`，页眉与遮罩都按它让位；
  面板内滚动时该值为 0。
- **只用 transform 缩放**，页眉在文档流里的高度不变，滚动时下方内容不会跳动。
- 遮罩用 `color-mix` 从 `--pro-canvas` 派生半透明档，改底色时只需改一个变量。

自查脚本：

- `verify-header.cjs`：375 / 460 / 1440 三档各测静止与滚动两态，断言容器透明、两块同底色
  且圆角、两块等高、总高 ≤64、触控区达标、贴顶位置正确、滚动后确实变小并向角落移动；
  输出 `verification/header-{375,460,1440}-{top,scrolled,nomask}.png` 与 `header-metrics.json`。
- `verify-header-pixels.py`：像素级复核。取两胶囊之间的间隙（避开投影）× 页眉顶端到胶囊
  下沿那片区域，断言「开遮罩时整片仍是底色」，并用「关掉遮罩的对照张」断言「同片区域确实
  被内容顶出来」——两个断言同时成立才说明遮罩真的在挡内容。

## 第五轮修订（页眉无边框 / 时间轴图标 / 卡片右上角切换）

| 项 | 修订前 | 修订后 |
| --- | --- | --- |
| 页眉本体 | 左右两个同底色圆角胶囊，中间留出的一段空隙把页眉切成两块 | 全部去掉底色、圆角、描边与投影，直接坐在页面底色上；左右内容各自贴页面留白（20px），中间自然留白 |
| 滚动收拢 | 两块 `scale(.8)` 并带投影加深 | 保留 `scale(.8)` + 向两侧各平移 6px、向上 2px，不再有投影变化 |
| 时间轴入口 | 首页页眉右侧是一颗**铃铛** | 换成时间轴图标（竖轴 + 三个节点 + 刻度），与底部导航、我的页菜单共用同一个 glyph |
| 卡片切换入口 | 卡片上方一行「卡片 / 照片版 / 简洁版」分段按钮 | 卡片**右上角**一个双箭头（⇄）小圆钮，44px 触控区，图标下有 30px 半透明白圆底 |
| 切换动画 | 点一下整页 `render()` 重绘 | 轨道里同时放新旧两张卡，`translateX(∓100%)` 横向滑动 420ms，结束后移除旧卡（`prefers-reduced-motion` 时即时切换，同样不重绘） |
| 问候行 | 只在简洁版显示，属于切换内容的一部分 | 常驻显示，不参与切换 |
| 卡片高度 | 照片版 196px、简洁版 168px | 统一 196px（滑轨需要两张卡等高，否则收尾会跳一下） |

实现要点：

- **卡片外层负责裁切，卡片自己不留圆角与投影**：`.banner-wrap{overflow:hidden; border-radius; box-shadow}`
  → `.banner-track{display:flex}` → `.banner-slide{flex:0 0 100%; display:flex}`
  → `.banner-wrap .banner-slide .life-banner{flex:1; min-height:196px; border-radius:0; box-shadow:none}`。
  选择器写到三层才压得住 `.life-banner.style-classic` 的 `min-height:168px`（同优先级时后者靠后胜出）。
- **切换按钮不能塞进卡片里**：卡片本身是个 `<button data-go="numbers">`，按钮里套按钮是非法
  HTML，点击也会串。所以按钮作为 `.banner-wrap` 的绝对定位兄弟节点，浮在卡片右上角。
- **方向可辨**：照片版 → 简洁版时新卡追加在轨道末尾（向左滑出，新卡从右侧进）；
  反向时把新卡 prepend 并把轨道先瞬移到 `-100%`，再动画回 0（从左侧进）。
- 旧卡滑动期间加 `inert`，避免可以被 Tab 到或重复点击。
- 无边框之后，页眉不再靠"框"来分隔页面，**遮罩（`::before` 同色渐变）成为唯一的遮挡手段**，
  这也是"内容不透过页眉"能成立的原因；像素级对照测试继续覆盖这一点。

自查脚本变化：

- `verify-header.cjs`：断言从「两块同底色 + 圆角」改为「底色透明、`border-radius:0`、
  `box-shadow:none`、`border-width:0`」，并新增「页眉的时间轴图标应与底部导航一致且是竖轴 glyph」。
- `verify-home-cards.cjs`：新增切换入口断言（位于卡片内、距右上角 ≤14px、双箭头 = 2 段、
  触控区 ≥44px、有小圆底）与横向滑动断言（滑动中轨道内 2 张卡、轨道 transform 非零、
  外层 `overflow:hidden`、两张卡等高、结束后只剩 1 张卡）；并用 DOM 探针证明切换过程中
  问候行与六宫格**没有被重绘**（不是整页刷新）。
