- 蓝天湖景封面、轻浮动照片、微光、进入按钮反馈、页面和底部弹层转场；遵循系统减弱动态效果设置。
- 六大模块入口、愿望、城市列表、第一次、美食、电影、数字、时间轴、搜索和记录详情。

- 完成愿望后才写入已完成状态；同一条记录进入时间轴、第一次和城市统计；删除关联记录后愿望恢复为想做。
- 初始展示示例数据，人生天数在自行填写生日后计算；无虚构累积数字。

数据仅存当前浏览器。沿用旧版数据时读取旧键并保留原值，新内容存入 `life-plus-one-v2`。不同浏览器、不同端口和直接打开文件的数据互不相通。

图片由上一版生图模型生成，位于 `assets/`；原 Word 图位于 `reference-images/`，供设计核对。本次沿用原素材，使用本机 `finesse-ui` 技能，产品方案中的色彩、尺寸和既有架构优先。

## V1.1 视觉校准

- 统一品牌色、文本色、圆角、触控尺寸与 460px 内容宽度；低饱和分类卡与照片保留原有色彩。
- 首页 Hero、六宫格和最近记录层级统一；最近记录照片保持 72×64，日期与城市同层展示。
- +记录弹层采用 18px 类型卡圆角，标题 23px，手写文字仅保留底部情绪句。
- 表单新增字数计数、照片预览与移除、就近错误、保存中禁用；存储失败保留输入，允许重试。
- 第一次和时间轴按年/月分组；人生数字主卡可下钻；分类筛选和按钮触控区至少 44px。
- 减弱动态设置关闭位移动画。原文件备份位于 `verification/before-v11/`。

`verify.cjs` 验证原有功能；`verify-ui.cjs` 验证新规范和失败恢复。测试使用独立临时浏览器上下文，不写入用户浏览器数据。尚未接入后端，因此本次验证不代表云端弱网、账号同步或真机验收。
